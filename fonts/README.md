# Keifont asset folder

Download the official Keifont package from https://font.sumomo.ne.jp/font_1.html, extract it, and place the font file named `keifont.ttf` in this folder.

The HTML files are configured to load `fonts/keifont.ttf` from this location. Do not rename the font file unless you also update both HTML files.

Keifont is published under the Apache License 2.0 according to the official distribution page. Follow the official license and keep any license/notice files included with the downloaded font package.
